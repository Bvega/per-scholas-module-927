# SBA 927 - Business Text Analytics: Natural Language Processing Techniques

## Project Objective

This project applies natural language processing (NLP) techniques to business text. Implementations are developed step-by-step for educational purposes, and the code will include explanatory comments.

## Technology Stack

- Python 3.11, managed with `uv`
- VS Code as the IDE
- Git and GitHub for version control

## Project Structure

```text
data/SBA927.txt  # Source dataset
src/             # Project source code
outputs/         # Generated analysis outputs
report/          # Per Scholas report materials
screenshots/     # Completion screenshots
```

The dataset is stored in `data/SBA927.txt`. Screenshots and the Per Scholas report will document completion of the project.

## NLP Tasks

The project will explore business text through incremental NLP tasks such as text preparation, linguistic analysis, feature extraction, and interpretation of results.

## Development Workflow

Work is completed in VS Code using the `uv`-managed Python 3.11 environment. Each NLP implementation is added and reviewed step-by-step, with explanatory comments supporting the educational goals of the project. Git and GitHub track the project history, while generated outputs, screenshots, and report materials provide evidence of completion.
